100mm by 200mm box
==================

Simple base to glue wooden sides to in order to make a box.

Base

V1: Used pegs on the corners

V2: Changed to a thinner wall and added a fillet for strength

V3: Changed to thicker wall and put in M3 threaded holes to attach outside walls

Sides

V1: Long sides with holes to attach to base
